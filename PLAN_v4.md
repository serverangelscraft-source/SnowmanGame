# SnowmanGame v4 plan

- Direct snowball rolling and drag-to-stack stays as the core mechanic.
- Decoration becomes direct drag-and-drop instead of menu buttons.
- Six draggable decoration groups: eyes, carrot, buttons, scarf, hat, arms.
- Placement accuracy affects score; imperfect drops remain visibly offset.
- One challenge is selected per run to encourage replay: precision, speed, or decoration accuracy.
- Timer, combo bonus, decoration accuracy, best score, and mission bonus are shown in the result.
- Layout remains responsive to narrow/short phones and Android system bars.
