# CAT ↔ DOG ↔ BOUQUET — 3D construction

Інтерактивна концептуальна 3D-модель трансформованої текстильної системи з синтепоном.

## Що показано

- **Хвіст**: 9 м’яких секцій («ковбасок»), приблизний крок строчок 5–6 см.
- **Кіт**: хвіст обгортає корпус і формує частину силуету.
- **Собака**: котяча голова підвертається під груди, хвіст стабілізує задню частину.
- **Букет**: 3 текстильні бутони + мордочка кота + мордочка собаки; один бутон утворюється спіральним складанням котячого хвоста.

## Як відкрити

Відкрийте `index.html` у сучасному браузері з доступом до інтернету. Three.js та OrbitControls завантажуються з CDN.

Мишкою або пальцем можна обертати модель. Кнопки зверху перемикають режими трансформації. Окремими прапорцями вмикаються поперечні строчки та приховані вузли.

## Орієнтовні параметри хвоста для реального крою

- готова довжина: 50–55 см;
- ширина біля основи: 9–10 см;
- ширина біля кінчика: 6–8 см;
- 8–10 секцій;
- поперечні строчки через 5–6 см;
- синтепон: орієнтовно 100–150 г/м², за потреби локально подвійний у ручці/основі.

Це геометричний макет для перевірки трансформації, а не фінальна виробнича лекальна модель.
