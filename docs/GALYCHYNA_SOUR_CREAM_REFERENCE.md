# Галичина — сметана в сцені вечері

Статус: visual reference for the SnowmanGame dinner scene.

## Референс

Офіційні матеріали ТМ «Галичина» показують сметану як білу молочну упаковку з виразним синім брендингом «ГАЛИЧИНА»; актуальний HoReCa-каталог має сметану 15% і 20%. Бренд також прямо пов'язує свою айдентику з Карпатами, природністю та українською/галицькою молочною традицією.

## Як переносимо в гру

Для вечері з дерунами не копіювати фотографію упаковки піксель-в-піксель. Замість безіменної білої плями біля дерунів намалювати маленький впізнаваний стаканчик/мисочку сметани:

- біла основа;
- синя верхня смуга/кришка;
- великий читабельний напис `ГАЛИЧИНА`;
- дрібний напис `СМЕТАНА`;
- маленький зелено-гірський акцент як відсилання до карпатської теми;
- сама сметана біла, густа, з м'яким світлим відблиском;
- ставити праворуч від золотистих дерунів, не перекривати їжу;
- на вузьких телефонах бренд має залишатися читабельним, тому не робити напис дрібнішим за інші допоміжні підписи сцени.

## Ігрова подача

На екрані вечері можна прямо писати `ДЕРУНИ + СМЕТАНА «ГАЛИЧИНА»` або коротко `СМЕТАНА • ГАЛИЧИНА`. Не називати це офіційною колаборацією/партнерством, якщо такого договору немає.
