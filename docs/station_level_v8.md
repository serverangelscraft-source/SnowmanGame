# Station level v8

The railway transition is now a real mini-level instead of a single button.

Flow:
1. Drag the snowman to the ticket office.
2. Select the ticket for the correct next life year.
3. Drag the issued game ticket into the validator.
4. Remember the wagon number printed on the ticket.
5. Drag the snowman to the correct wagon door.
6. Watch boarding and the trip.
7. Arrive in the next life year.

Fixes:
- Dynamic speech now matches the current year and actual ticket price.
- First transition (Year 1 -> 2) remains free; later transitions use game coins.
- System bar insets are respected so controls do not collide with Android navigation.
- Mistakes and station time are tracked to make the transition more game-like.
- This is an in-game fictional travel scene and ticket, not an official Ukrzaliznytsia service or real fare.
